# 离线 mock 测试（不接硬件）

用 Lua 5.4 模拟 SKYdimo 的 `device` 对象，直接跑插件的 `main.lua` / `lib/*.lua`，
校验它发出的每一个 HID 包——**不需要键盘，不需要 SKYdimo**。

## 依赖

```bash
pip install lupa          # Python 里的 Lua 5.4 运行时
```

## 用法

```bash
cd adapters/skydimo/best-effects/tests
python mock-test-wireless.py
```

输出 JSON 报告到系统临时目录，包含 `passed` / `checkCount` / 完整 MAP。
**当前状态：34 项断言全部通过。**

## 覆盖了什么

| 场景 | 期望命令序列 |
|---|---|
| 初始化 + 首帧 | `19` + `20`×10 + `27, 29` + `36`×10 + `35, 43, 45` |
| 后续变化帧 | 仅变化的 `36` 分包（`last=0`），不发 `35` |
| 单键变化 | 1 个 `36` 分包 |
| 写失败后 | 下一帧完整重新同步 |
| 关闭 | `36`×10 + `35, 43, 45`，状态回到快照原值 |
| `device:write` 异常 | 短写 / `0` / `false` / `nil` / 抛异常，全部不崩溃 |
| 快照缺失 | 拒绝改灯（不破坏键盘现场） |
| 休眠唤醒 | `on_tick` 里重试初始化 |

同时校验：

- 每包必须是 65 字节、`reportId=0`、`0xAA` 开头；
- 只发白名单命令（16/19/20/27/29/35/36/43/45）；
- 矩阵为 19×6 / 101 采样点（87 键 + 2 环 + 12 侧灯）；
- manifest 的匹配规则未被改动。

## 局限

**这只是 Lua 层的 mock，不涉及真实硬件。** 它验证「插件发的包是对的」，
不能验证 SKYdimo 的实际渲染、也不能验证灯珠是否真的亮、更不测真实帧率。

有线插件目前没有对应的 mock 脚本——欢迎 PR。
